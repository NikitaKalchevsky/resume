04 LIVE · COMMERCIAL

Airbag ECU Lookup Bot

A production Telegram bot serving real customers for an automotive ECU programming service in Glendale, CA. Customers send a vehicle brand and part number; the bot queries a 16,003-record database, returns the correct reprogramming method and price, and books an appointment within an hour. Claude Haiku handles messy natural-language inputs.

  • Two-bot architecture: client-facing bot plus admin management panel
  • Production deploy: Ubuntu droplet, persistent screen sessions, cron auto-restart every 6h
  • Lean ops: 89MB memory footprint, runs comfortably on 1GB RAM / 1 vCPU
  • API tuning: eliminated Claude 400 errors via prompt plus DB chunking and temperature 0.1

stack: Python · Claude Haiku API · python-telegram-bot · openpyxl · DigitalOcean · Linux/cron
